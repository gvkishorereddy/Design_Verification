# AXI-Lite examples

Start with [simple/README.md](simple/README.md) for the simplified generator-based
version matching the current Playground: https://www.edaplayground.com/x/kZRD

It uses separate transaction, generator, driver, independent monitor and
scoreboard files, with no separate test class or automatic readback loop.

The original `src/` and `testbench/` remain the older learning example; the new
simple example's validation results apply only to `simple/`.
